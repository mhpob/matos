# Place where functions live for the matos\_\*\_summary family of functions

Place where functions live for the matos\_\*\_summary family of
functions

## Usage

``` r
act_file_download(
  type,
  temp_dir = NULL,
  matos_project = NULL,
  project_files = NULL
)
```

## Arguments

- type:

  type of data: qualified or unqualified detections; or deployment
  metadata

- temp_dir:

  location of temporary directory

- matos_project:

  matos project number

- project_files:

  qualified/unqualified detection files
